# Hermes 离线安装包 · 使用说明

> 给不太懂电脑的同学看的超简单教程，照着做就行，全程不需要敲任何命令。

---

## 一、这是什么？

Hermes 是一个 AI 助手（跟 ChatGPT、DeepSeek 类似，但更强大，能帮你查资料、写代码、改文件、浏览网页）。

这个包是**完整离线版**：所有程序（包括浏览器、语音、Git 等工具）都已经打好了，装的时候**不需要联网下载任何东西**，适合校园网这种访问国外网站很慢的环境。

---

## 二、怎么安装？（三步）

### 第 1 步：解压
把 `Hermes-离线安装包.zip` 解压到任意位置（比如桌面或 D 盘）。
解压后会有一个文件夹，里面有：
- `install.bat`（安装脚本）
- `payload`（程序本体，3GB 左右）
- `relocate.py`（自动路径修复脚本）
- `使用说明.txt`（就是本文档）

### 第 2 步：双击运行
**双击 `install.bat`**，会弹出一个黑色窗口，显示中文安装进度。
它会自动：
1. 复制程序文件（约 1~3 分钟，请耐心等，别关窗口）
2. 自动适配你的电脑用户名
3. 在桌面创建「Hermes」快捷方式

看到「**安装成功！**」就完成了。

> ⚠️ 如果 Windows 弹出蓝色「Windows 已保护你的电脑」提示，点「**更多信息**」→「**仍要运行**」。这是正常现象（因为脚本没做数字签名）。

### 第 3 步：打开 Hermes
双击桌面上的 **Hermes** 图标，第一次打开会让你配置模型和 API Key。

---

## 三、API Key 怎么填？

Hermes 需要连接一个大模型（AI 大脑）才能用，你需要一个 **API Key**。

推荐用国内的 DeepSeek（便宜、稳定、校园网友好）：
1. 打开 https://platform.deepseek.com
2. 注册账号，充值一点点（几块钱就够用很久）
3. 在「API Keys」页面创建一个 Key，复制下来（`sk-` 开头的一串）
4. 回到 Hermes，在设置里选择 DeepSeek 模型，粘贴你的 Key

> Key 是你自己的，只有你自己能创建，任何人都替代不了这一步。

## 四、常见问题

| 问题 | 怎么办 |
|------|--------|
| 双击 install.bat 没反应 | 右键 → 以管理员身份运行 |
| 提示「Windows 已保护你的电脑」 | 点「更多信息」→「仍要运行」 |
| 复制到一半卡住 | 正常，3GB 文件慢，多等几分钟 |
| 桌面没有 Hermes 图标 | 去 `C:\Users\你的用户名\AppData\Local\hermes\hermes-agent\apps\desktop\release\win-unpacked\` 找 `Hermes.exe` 双击 |
| 想卸载 | 直接删掉 `C:\Users\你的用户名\AppData\Local\hermes` 整个文件夹 |

## 五、关于这个包的版本

这是**完整版**，包含 Hermes 的全部能力：
- 文字聊天、写代码、查资料
- 浏览器网页操作
- 语音、音频/视频处理
- Git 版本管理
- 电脑自动化操作

以后有网了想升级到最新版，运行 `hermes update` 即可（可选，不升级也完全能用）。
